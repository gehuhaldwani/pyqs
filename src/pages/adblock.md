# How to Block Ads (H2BA)

I often see the same questions over and over again being asked, and so I wanted to make an all-in-one guide on ad-blocking for every platform that people could link to whenever a question is asked.

### Is it legal?

Short answer yes. So lets move on

## Desktop

#### Chromium users 

For Chromium-based browsers (Google Chrome, Microsoft Edge, Opera, Vivaldi, etc.):

Basic:
- Adguard [Extension](https://chromewebstore.google.com/detail/adguard-adblocker/bgnkhhnnamicmpeenaelnjfhikgbkllg)
- uBlock Origin Lite [Extension](https://chromewebstore.google.com/detail/ublock-origin-lite/ddkjiahejlhfcafbddmgiahcphecmpfh)

Advanced:
- Heilum [Browser](https://helium.computer/) *Editor's choice
- Brave [Browser](https://brave.com/)

#### Firefox users

- Ublock Origin [Extension](https://addons.mozilla.org/en-US/firefox/addon/ublock-origin/)

#### Safari users

- Adguard [Extension](https://apps.apple.com/us/app/adguard-adblock/id1440147259?mt=12)

### Android users

- Brave Browser [App](https://play.google.com/store/apps/details?id=com.brave.browser)
- Firefox [App](https://play.google.com/store/apps/details?id=org.mozilla.firefox) + uBlock Origin [Extension](https://addons.mozilla.org/en-US/firefox/addon/ublock-origin/)
- Adguard [App](https://play.google.com/store/apps/details?id=com.adguard.android.contentblocker)

### iOS users

- Brave Browser [App](https://apps.apple.com/us/app/brave-private-web-browser/id1052879175)
- Adguard for Safari [App](https://apps.apple.com/us/app/adguard-adblock/id1047223162?mt=8)


> Do NOT use multiple ad-blockers. It doesn't make the ad-block better, it makes your performance worse as the 2 ad-blockers will fight over each other: https://xcancel.com/gorhill/status/1033706103782170625
